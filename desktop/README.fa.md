# آزمایشگاه دسکتاپ ملاکات

[نسخهٔ انگلیسی](README.md)

این پوشه، برنامهٔ دسکتاپ و موتور اجرای محلی پروژهٔ ملاکات را نگهداری می‌کند.

## وضعیت فعلی

رابط دسکتاپ به‌صورت پیش‌فرض از موتور زیر استفاده می‌کند:

<code>phase-zero-vm-0.2</code>

موتور در یک فرایند جدا از رابط کاربری اجرا می‌شود. رابط فقط فرمان‌های قابل‌سریال‌سازی ارسال می‌کند و رویدادها و <code>snapshot</code>های قابل‌سریال‌سازی دریافت می‌کند.

موتور آزمایشی قدیمی نیز با نام <code>demo</code> باقی مانده است تا مسیر معماری با آن مقایسه شود.

## هدف‌های طراحی

- فرم پارامترها از روی <code>schema</code> ساخته می‌شود.
- افزودن پارامتر جدید به بازطراحی پنجره نیاز ندارد.
- موتور و رابط کاربری در فرایندهای جدا اجرا می‌شوند.
- معیارهای علمی در رابط کاربری محاسبه نمی‌شوند.
- رابط برای رشد از ۵۰ تا ۲۰۰ پارامتر آماده است.
- پیکربندی و نتیجهٔ ذخیره‌شده می‌تواند در آینده مرز میان دسکتاپ و ابزارهای وب باشد.

## فناوری‌ها

- <code>Python</code>
- <code>PySide6</code>
- <code>PyQtGraph</code>
- <code>multiprocessing</code>
- <code>PyInstaller</code> برای بسته‌بندی ویندوز

## اجرای محلی در ویندوز

از نسخهٔ پایدار <code>Python</code> استفاده کنید. نسخهٔ آزمایشی بسیار قدیمی مانند <code>Python 3.12.0a4</code> می‌تواند با ابزارهای بسته‌بندی مشکل ایجاد کند.

~~~powershell
cd desktop
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e .
cd ..
python -m melakat_desktop.main
~~~

برای اجرای آزمون‌ها:

~~~powershell
cd desktop
python -m unittest discover -s tests -v
~~~

برای اجرای آزمایش بدون رابط:

~~~powershell
cd desktop
python -m melakat_desktop.phase_zero_experiment --runs 30 --ticks 2000 --output phase-zero-results.json
~~~

برای گرفتن خروجی پژوهشی کامل‌تر:

~~~powershell
python -m melakat_desktop.phase_zero_experiment --runs 30 --ticks 2000 --output phase-zero-results.json --summary-csv phase-zero-summary.csv --history-csv phase-zero-history.csv
~~~

## پیاده‌سازی نسخهٔ ۰٫۲ مرحلهٔ یک

دروازهٔ پیاده‌سازی مرحلهٔ یک کامل شده است:

- نتیجهٔ نسخه‌گذاری‌شده با قالب <code>melakat-run-artifact-0.1</code>؛
- بارگذاری مستقل نتیجه همراه با اعتبارسنجی <code>hash</code> پیکربندی؛
- تحلیل دودمان، ژنوتیپ، طول عمر، علت مرگ و رویدادهای <code>mutation</code>؛
- اجرای <code>--config</code> با پیکربندی صادرشده از رابط؛
- اجرای کنترل چند <code>seed</code> و <code>--sweep</code> تک‌عاملی؛
- ابزار <code>melakat-compare</code> و مقایسهٔ نتیجه‌ها در رابط؛
- بازکردن نتیجهٔ ذخیره‌شده و بازرسی موجود انتخاب‌شده؛
- خروجی دفتر حساب منابع در هر گام در فایل‌های تاریخی <code>CSV</code>؛
- ۳۰ آزمون واحد موفق برای موتور، ماشین مجازی، نتیجه‌ها، آزمایش‌ها و کارگر.

ماتریس کامل خط پایه و حساسیت هنوز باید به‌عنوان شواهد پژوهشی اجرا و بایگانی شود. پیاده‌سازی آماده است و کارزار شواهد به‌صورت بی‌صدا کامل فرض نشده است.

## قابلیت‌های رابط

- ویرایش گروه‌بندی‌شدهٔ پارامترها؛
- جست‌وجوی پارامتر؛
- شروع، مکث، ادامه، گام، توقف و بازنشانی؛
- نمایش زندهٔ جهان؛
- نمودار جمعیت و انرژی؛
- گزارش رویدادهای تولد و مرگ؛
- نمایش نسخهٔ موتور و نسخهٔ اندازه‌گیری؛
- نمایش <code>hash</code> پیکربندی؛
- نمایش ژنوتیپ فعال و تاریخی؛
- نمایش دودمان، تقسیم مسدود و انتظار برای منابع؛
- خروجی پیکربندی و نتیجه.

## مرز موتور

ماشین مجازی فقط ژنوم‌های دستور داده‌محور را می‌پذیرد. موجودات نمی‌توانند کد میزبان <code>Python</code> را اجرا کنند، ماژول وارد کنند، به فایل‌ها و شبکه دسترسی داشته باشند، فرایند بسازند یا از <code>API</code> خارجی استفاده کنند.

رابط باید مشاهده‌کننده و کنترل‌کننده بماند و نباید قانونی را که در قرارداد موتور وجود ندارد، بی‌صدا اضافه کند.

## توسعهٔ بعدی مرحلهٔ یک

- بازرس و نمایش تصویری دودمان؛
- مقایسهٔ اجراها؛
- بارگذاری مستقل نتیجه؛
- ماتریس حساسیت پارامترها؛
- بازپخش قطعی؛
- گزارش رویداد خلاصه با امکان مشاهدهٔ جزئیات؛
- نمایش نتیجه در اسبیکو در یک مرحلهٔ ادغام آینده.
