## سؤال‌های مشترک

برای هر پروژه باید بررسی شود:

1. واحد organism دقیقاً چیست؟
2. genome چگونه نمایش داده می‌شود؟
3. interpreter یا VM چه instructionهایی دارد؟
4. تکثیر از کجا می‌آید؟
5. mutation چگونه رخ می‌دهد؟
6. انرژی، زمان و حافظه چگونه مدل می‌شوند؟
7. آیا fitness از بیرون تعریف شده یا از پویایی جهان پدیدار می‌شود؟
8. competition دقیقاً بر سر چیست؟
9. مرگ و recycling چگونه رخ می‌دهد؟
10. آیا parasite، cooperation یا ecology از ابتدا وارد شده‌اند؟
11. نتیجهٔ تجربی چه بوده است؟
12. کدام بخش را می‌توان به‌عنوان analogue معتبر پذیرفت؟
13. کدام بخش بیش‌ازحد به نتیجه جهت داده است؟
14. برای آزمایش اولیهٔ Melakat چه چیزی را نباید کپی کنیم؟
