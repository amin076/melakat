## Recommended reading order

1. Read the [Phase Zero results](phase-zero-results.md) for the original executable organism/world baseline.
2. Read the [Phase One evidence report](phase-one-evidence-report.md) for the accepted homogeneous experimental evidence.
3. Read the [Phase Two roadmap](phase-two-roadmap.md) to understand the hypotheses, work packages, exit criteria, and explicit non-goals.
4. Read the [Phase Two completion and evidence report](../phase-2/phase-two-completion-report.md) for what was actually implemented and accepted.
5. Use the [Phase Two user test guide](../phase-2/phase-two-user-test-guide.md) to reproduce automated tests and manually inspect the desktop laboratory.
6. Read the [desktop architecture](../desktop/desktop-lab-architecture.md) and [Phase Zero VM contract](../desktop/phase-zero-vm.md) for process and execution boundaries.

The current Phase Two scientific contract is versioned in `desktop/src/melakat_desktop/world_contract.py`. Historical Phase Two milestone documents under `docs/phase-2/` remain part of the design record.
