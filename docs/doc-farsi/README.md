## وضعیت پروژه

مرحلهٔ صفر، مرحلهٔ یک و مرحلهٔ دو برای گیت‌های پژوهشی تعریف‌شدهٔ خود کامل شده‌اند. مرحلهٔ یک کنترل همگن دائمی باقی می‌ماند و مرحلهٔ دو نسخهٔ مرجع پذیرفته‌شدهٔ فضایی/محیطی است.

## ترتیب پیشنهادی مطالعه

۱. [نتایج مرحلهٔ صفر](phase-zero-results.md) را برای شناخت نخستین جهان و موجود اجرایی بخوانید.

۲. [گزارش شواهد مرحلهٔ یک](phase-one-evidence-report.md) را برای شناخت شواهد پذیرفته‌شدهٔ جهان همگن بخوانید.

۳. [نقشهٔ راه مرحلهٔ دو](phase-two-roadmap.md) را برای فرضیه‌ها، بسته‌های کاری، معیارهای خروج و non-goalهای مرحلهٔ دو بخوانید.

۴. [گزارش تکمیل و شواهد مرحلهٔ دو](../phase-2/phase-two-completion-report.fa.md) را برای آنچه واقعاً پیاده‌سازی و پذیرفته شده است بخوانید.

۵. برای اجرای آزمون‌های خودکار و بررسی دستی آزمایشگاه دسکتاپ از [راهنمای تست کاربر مرحلهٔ دو](../phase-2/phase-two-user-test-guide.fa.md) استفاده کنید.

۶. برای مرزهای پردازشی و اجرایی، [معماری آزمایشگاه دسکتاپ](../desktop/desktop-lab-architecture.fa.md) و [قرارداد ماشین مجازی مرحلهٔ صفر](../desktop/phase-zero-vm.fa.md) را بخوانید.

قرارداد علمی فعلی مرحلهٔ دو در `desktop/src/melakat_desktop/world_contract.py` نسخه‌گذاری شده است. اسناد تاریخی مرحلهٔ دو در `docs/phase-2/` نیز به‌عنوان سابقهٔ طراحی حفظ می‌شوند.

این پوشه محل اصلی اسناد پژوهشی فارسی است. اسناد هماهنگ انگلیسی در `docs/doc-english/` و `docs/phase-2/` نگهداری می‌شوند.
