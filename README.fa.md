# ملاکت

[نسخهٔ انگلیسی](README.md)

ملاکت یک پروژهٔ پژوهشی برای بررسی پیدایش فرایندهای شبیه به حیات و تکامل در یک جهان محاسباتی محدود است.

در این پروژه، برنامه‌های بسیار کوچک درون یک ماشین مجازی محدود اجرا می‌شوند. این برنامه‌ها انرژی و حافظه مصرف می‌کنند، خود را تکثیر می‌کنند، <code>mutation</code> وراثتی دارند، برای منابع محدود رقابت می‌کنند و ممکن است از بین بروند.

## وضعیت فعلی

مرحلهٔ صفر پیاده‌سازی و اعتبارسنجی شده است. مرحلهٔ یک نیز اکنون هم از نظر پیاده‌سازی و هم از نظر دروازهٔ شواهد علمی برای خط پایهٔ همگن تعریف‌شده کامل است.

نسخهٔ فعلی موتور <code>phase-zero-vm-0.2</code> است و این قابلیت‌ها را دارد:

- ماشین مجازی محدود و داده‌محور؛
- ثبات، کلمه و حافظهٔ کاری محدود؛
- تولیدمثل از راه کپی خود؛
- دریافت انرژی محیطی و انرژی داخلی؛
- هزینهٔ محاسبه، نگهداری و تولیدمثل؛
- حافظهٔ ساختاری محدود؛
- <code>mutation</code> کور از نوع جایگزینی دستور؛
- وراثت، نسل، دودمان و <code>genome hash</code>؛
- تولد، مرگ و علت مرگ؛
- حسابداری انرژی و حافظه؛
- اجرای قطعی با <code>seed</code>؛
- رابط دسکتاپ برای مشاهدهٔ اجرای زنده و نتیجهٔ ذخیره‌شده؛
- خروجی نسخه‌گذاری‌شدهٔ <code>JSON</code> و <code>CSV</code>؛
- تحلیل دودمان، ژنوتیپ، <code>mutation</code> و علت مرگ؛
- اجرای چند <code>seed</code> برای کنترل و حساسیت؛
- مقایسهٔ نتایج ذخیره‌شده.

کارزار پذیرفته‌شدهٔ شواهد مرحلهٔ یک شامل ۹۹۰ اجراست: ۳۰ <code>seed</code> در شش وضعیت کنترل و ۲۷ حالت حساسیت تک‌عاملی، با طول <code>2000 tick</code> برای هر اجرا. هیچ شکست ثبت‌شده‌ای در حساب انرژی، حافظه، پوشش <code>seed</code>، تعداد اجرا، <code>config_hash</code>، <code>checksum</code> نتیجه یا تعداد <code>tick</code> رخ نداد. بیشترین خطای مطلق تراز انرژی <code>2.5e-08</code> در برابر تلورانس <code>1e-07</code> بود.

کنترل بدون <code>mutation</code> در هر ۳۰ <code>seed</code> یک ژنوتیپ، یک دودمان، صفر رویداد <code>mutation</code>، صفر خطای ماشین مجازی و صفر مرگ ایجاد کرد. آزمایش حساسیت همچنین نشان داد جهان پایهٔ ۵۰۰ واحدی عمدتاً با حافظهٔ ساختاری محدود می‌شود، در حالی که افزایش حافظه یا کاهش انرژی می‌تواند سیستم را وارد یک رژیم محدودشده با انرژی و دارای گردش زیاد تولد/مرگ کند.

این نتایج دربارهٔ مدل دیجیتال پیاده‌سازی‌شده هستند و ادعای بازسازی حیات زیستی ندارند.

## مرزهای پژوهشی

خط پایهٔ پذیرفته‌شدهٔ مرحلهٔ یک همگن، محدود از نظر منابع و کاملاً محصور در ماشین مجازی سفارشی است.

این خط پایه عمداً شامل این موارد نیست:

- یادگیری ماشین و شبکهٔ عصبی؛
- هدف هوشمندی؛
- تابع <code>fitness</code> صریح؛
- انتخاب دستی موجودات موفق؛
- همکاری، حمله، انگل یا بیماری؛
- جغرافیای فضایی و محیط ناهمگن؛
- پاداش پیچیدگی؛
- دسترسی موجود به فایل‌سیستم، شبکه، <code>subprocess</code>، محیط میزبان یا <code>API</code> بیرونی.

فرایند <code>Python</code> فقط شبیه‌ساز میزبان است و موجودات کد <code>Python</code> اجرا نمی‌کنند.

## ساختار مخزن

- <code>desktop/</code> — برنامهٔ دسکتاپ و موتور <code>Python</code>؛

## اجرای محلی

~~~powershell
cd desktop
python -m venv .venv
.venv/Scripts/Activate.ps1
python -m pip install -e .
cd ..
python -m melakat_desktop.main
~~~

برای اجرای آزمون‌ها:

~~~powershell
cd desktop
python -m unittest discover -s tests -v
~~~

## بازتولید کارزار مرحلهٔ یک

کارزار کامل عمداً با هر <code>push</code> اجرا نمی‌شود. برای بازتولید آگاهانهٔ آن می‌توان از گردش‌کار دستی <code>Phase One evidence campaign</code> در <code>GitHub Actions</code> استفاده کرد یا این فرمان را اجرا کرد:

~~~powershell
melakat-phase-one-evidence --runs 30 --ticks 2000 --seed-start 1 --output-dir results/phase-one/evidence-gate
~~~

هر کارزار دوباره‌تولیدشده باید پیش از جایگزین‌کردن آرشیو پذیرفته‌شده با آن مقایسه شود.

## گام بعد: مرحلهٔ دو

مرحلهٔ دو اکنون می‌تواند با <code>P2.1</code>، یعنی قرارداد نسخه‌گذاری‌شدهٔ مدل جهان و حالت سازگاری با خط پایه آغاز شود. خط پایهٔ همگن مرحلهٔ یک باید بدون تغییر به‌عنوان کنترل دائمی حفظ شود. مرز فضایی، منابع محلی، حرکت و مشاهده فقط در بسته‌های مستقل بعدی و پس از قبولی قرارداد سازگاری <code>P2.1</code> اضافه خواهند شد.
