# ملاکات

[نسخهٔ انگلیسی](README.md)

ملاکات یک پروژهٔ پژوهشی برای بررسی پیدایش فرایندهای شبیه به حیات و تکامل در یک جهان محاسباتی محدود است.

در این پروژه، برنامه‌های بسیار کوچک درون یک ماشین مجازی محدود اجرا می‌شوند. این برنامه‌ها انرژی و حافظه مصرف می‌کنند، خود را تکثیر می‌کنند، <code>mutation</code> وراثتی دارند، برای منابع محدود رقابت می‌کنند و ممکن است از بین بروند.

## وضعیت فعلی

مرحلهٔ صفر پروژه اکنون در رابط دسکتاپ اجرا و اعتبارسنجی شده است. این مرحله شامل ماشین مجازی محدود، ژنوم داده‌محور، حافظهٔ محدود، انرژی ورودی، هزینهٔ اجرا، هزینهٔ نگهداری، هزینهٔ تولیدمثل، <code>mutation</code> از نوع جایگزینی، وراثت، تولد، مرگ و حسابداری انرژی و حافظه است.

مرحلهٔ صفر ادعای بازسازی زیست‌شناسی زمین را ندارد. هدف آن، اعتبارسنجی قوانین پایهٔ یک جهان دیجیتال محدود است.

## نتیجهٔ اصلی اعتبارسنجی

در اجرای کنترل‌شده با حداکثر <code>1000 tick</code> و ظرفیت حافظهٔ <code>2000</code>:

- با <code>Substitution rate = 0.01</code>، تعداد <code>Faults</code> برابر <code>8</code> و تعداد ژنوتیپ‌های فعال برابر <code>3</code> بود.
- با <code>Substitution rate = 0</code>، تعداد <code>Faults</code> برابر <code>0</code> و تعداد ژنوتیپ‌های فعال برابر <code>1</code> بود.
- در هر دو اجرا، تولد و مرگ ادامه داشتند.
- خطای حساب انرژی در حد خطای گردکردن عددهای اعشاری و نزدیک به صفر بود.

این نتیجه نشان می‌دهد که <code>mutation</code> در مدل اثر قابل‌اندازه‌گیری دارد و موتور فقط مقادیر ثابت رابط کاربری را نمایش نمی‌دهد.

## مرزهای فعلی

مرحلهٔ صفر عمداً هوش مصنوعی، یادگیری ماشین، شبکهٔ عصبی، هدف صریح افزایش پیچیدگی، تابع <code>fitness</code> صریح، جغرافیا، محیط ناهمگن، حمله، انگل، بیماری، همکاری، بلایای محیطی و دسترسی به شبکه، فایل‌سیستم یا سیستم‌عامل را ندارد.

## اجرای محلی

~~~powershell
cd desktop
python -m venv .venv
.venv/Scripts/Activate.ps1
python -m pip install -e .
cd ..
python -m melakat_desktop.main
~~~

برای اجرای آزمون‌ها:

~~~powershell
cd desktop
python -m unittest discover -s tests -v
~~~
